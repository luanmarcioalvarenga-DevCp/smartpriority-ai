# SmartPriority — Workspace de tarefas

Aplicação responsiva de gerenciamento de tarefas com quadro Kanban, organização por prioridade e planejamento diário.

## Funcionalidades
- Criar, editar, excluir e concluir tarefas
- Mover tarefas entre colunas por arrastar e soltar ou por botões
- Prioridade calculada por regras de prazo, impacto e esforço
- Indicadores, planejamento e progresso
- Pesquisa e filtros
- Persistência local com `localStorage`
- Layout responsivo e dados demonstrativos iniciais

## Tecnologias
HTML5, CSS3 e JavaScript puro (sem dependências ou backend).

## Executar
Abra `index.html` em um navegador moderno ou utilize a extensão Live Server do VS Code.

## Observações
Os dados são armazenados **somente neste navegador**. Não existe conta, sincronização na nuvem nem integração com modelo de IA generativa. O termo “inteligente” refere-se ao algoritmo de pontuação por regras. Dados iniciais são fictícios.
